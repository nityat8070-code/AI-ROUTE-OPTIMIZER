03 — THE MATHEMATICS

Two methods. One objective.

Both methods approximate a root of the optimization equation using different numerical strategies.

01

Newton-Raphson

Uses the function and its derivative to move toward a root through successive tangent-line estimates.

wₙ₊₁ = wₙ − f(wₙ) / f′(wₙ)
02

Bisection

Repeatedly halves an interval whose endpoints have function values with opposite signs.

m = (a + b) / 2
